Install Prusa Shutter

Version 3.0.0

  1. Connect the ESP32 by USB. Disconnect printer wiring.
  2. Click Install and select the USB device.
  3. Open Logs & Console and press EN/RESET to see your passwords.

ESP32-WROOM-32 / DevKit, 4 MB minimum. Desktop Chrome or Edge.

Checking browser…

Use desktop Chrome or Edge.Open over HTTPS or localhost.

Installer failed to load. Reload the page.

Version 1 → 2: Select Erase device. This removes settings and pairings.

After flashing

Wi-Fi Prusa-Shutter → 192.168.4.1
User: admin. Passwords: „Logs & Console“, 115200 Baud.

No USB device?

Check the data cable and CP210x/CH340 driver. Close other serial monitors.

Connection stuck?

Hold BOOT while connecting, then release. Press EN/RESET after flashing if needed.
